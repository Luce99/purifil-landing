# Purifil Internacional - Landing Page

Landing page para **Purifil Internacional**, empresa colombiana especializada en purificadores de agua, aire y utensilios de cocina premium.

## Descripción

Sitio web estático diseñado para mostrar el catálogo de productos de Purifil Internacional y dirigir a los usuarios a contactar por WhatsApp para realizar compras y recibir asesoría personalizada.

## Características

- Diseño moderno y responsivo (mobile-first)
- Catálogo de productos con filtros por categoría
- Botón flotante de WhatsApp para contacto directo
- Animaciones de scroll suaves
- Sección de testimonios de clientes corporativos
- Información de contacto completa
- Optimizado para SEO básico
- Sin dependencias de frameworks (HTML + CSS + JS vanilla)

## Estructura del Proyecto

```
Purifil/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos del sitio
├── js/
│   └── main.js         # JavaScript para interactividad
├── img/                # Imágenes locales (si se agregan)
└── README.md           # Este archivo
```

## Tecnologías

- **HTML5** - Estructura semántica
- **CSS3** - Custom Properties, Grid, Flexbox, animaciones
- **JavaScript** - Vanilla JS, Intersection Observer API
- **Google Fonts** - Inter, Playfair Display
- **Font Awesome 6** - Iconos

## Despliegue

Este proyecto está optimizado para ser desplegado en **GitHub Pages**:

1. Subir el código a un repositorio de GitHub
2. Ir a Settings > Pages
3. Seleccionar la rama `main` y carpeta `/ (root)`
4. El sitio estará disponible en `https://<usuario>.github.io/<repo>/`

## Desarrollo Local

Simplemente abre `index.html` en tu navegador o usa un servidor local:

```bash
# Con Python
python -m http.server 8000

# Con Node.js (npx)
npx serve .
```
